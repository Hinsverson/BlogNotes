# HTML

HTML元素结构：

![](HTML/2302D1DF-D7AE-4FBC-A3F3-0CF571985183.png)
一个元素由开始标签-内容-结束标签组成。

属性：
一个元素可以有属性，Class是属性名，“editor-note”是属性的值。
![](HTML/9DD2A9A4-A21F-46BB-9371-42291F7E3585.png)

元素嵌套：嵌套的元素顺序必须正确
正确：<p>我的猫咪脾气<strong>爆</strong>:)</p>
错误：<p>我的猫咪脾气<strong>爆:)</p></strong>

空元素：元素里没有内容（scr，alt为2个属性，属性间空格分开
