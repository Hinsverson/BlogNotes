# 基本概念
### 排序算法的稳定性（Stability）
排序算法的稳定性是指如果相等的2个元素，在排序前后的相对位置保持不变，那么这是稳定的排序算法。

### 原地算法（In-place Algorithm）
不依赖额外的资源或依赖少数的额外资源，仅依靠输出来覆盖输入。空间复杂度为O(1)的都可以认为是原地算法。

### 复杂度
冒泡、选择、插入的平均复杂度都是O(n^2)
归并、快排、堆的平均复杂度是O(nlogn)
希尔排序取决于步长，目前已知的最好的步长下最坏情况时间复杂度是O(n^4/3)

# 一些理解
* 堆排序是选择排序的一种优化。
* 插入排序的时间复杂度与逆序对的数量成正比，当逆序对的数量极少时，插入排序的效率特别高，甚至速度比O(nlogn)级别的快速排序还要快，数据量不是特别大的时候，插入排序的效率也是非常好的。
* 希尔排序从n列变为1列的过程中，逆序对的数量在逐渐减少，因此希尔排序底层一般使用插入排序对每一列进行排序，并且时间复杂度和选用的步长序列有关，目前已知的最好的步长序列，最坏情况时间复杂度是O(n^4/3)

# 冒泡、选择、插入排序
``` swift
func sort(nums: inout [Int]) {
    for i in 0..<nums.count-1 {
        //不同的冒泡、选择、插入排序处理
    }
}
```

冒泡：从`[nums.count-1, i)` 内从后往前和前面的每一个数比小交换，最终每趟沉淀一个最小数到头部i后的位置。
        * 优化点1：观察每躺排序是否发生了交换，没有发生交换说明有序，不排了。
        * 优化点2：纪录每趟最后一次发生交换的j位置（说明前面已经有序比它小），将其作为下一趟循环的截止位置。
``` swift
///var isSwap = false
for j in stride(from: nums.count-1, to: i, by: -1) {
    if nums[j] < nums[j-1] { 
		  nums.swapAt(j, j-1)/*; isSwap = true*/ 
	  }
}
///if !isSwap { break }
//*/
```

选择：从`[i+1, size)`内从前往后先标记找无序数里最小的数，然后和i位置的数交换。
``` swift
var minIndex = i
for j in i+1..<nums.count {
    if nums[j] < nums[minIndex] { minIndex = j }
}
nums.swapAt(i, minIndex)
```

插入：从`[i+1, 0)` 内倒序交换，前面i个数已经有序，插入i+1这个数到前面的有序数组中。
``` swift
for j in stride(from: i+1, to: 0, by: -1) {
    if (nums[j] < nums[j-1]) { nums.swapAt(j, j-1) }
}
```

# 快速
``` swift
// 原地交换，所以传入交换索引
func quickSort(_ nums:inout [Int],_ start: Int,_ end: Int) {
    guard start < end, end < nums.count else { return }
    // 分治法：divide
    let pivot = partition(&nums, start, end)
    quickSort(&nums, 0, pivot-1)
    quickSort(&nums, pivot+1, end)
    //把一个数组分为左右两段，左段小于右段，类似分治法，因为原地没有合并过程
}
// 分区
func partition(_ nums:inout [Int],_ start: Int,_ end: Int) -> Int {
    let p = nums[end] //参考点。排序：比p小的在左边，比p大的在右边
    var i = start
    for j in start..<end {
        //找比p小的数和i交换位置
        if nums[j] < p {
            nums.swapAt(i, j)
            i += 1
        }
    }
    // 把中间的值换为用于比较的基准值
    nums.swapAt(i, end)
    return i
}
```

# 归并
分治思想，先递归划分，最后合并。
时间复杂度： nlogn ，空间复杂度：O(N)
``` swift
func mergeSort(_ nums: [Int]) -> [Int] {
    if nums.isEmpty { return nums }
    // 分治法：divide 分为两段
    let mid = nums.count / 2
    let left = mergeSort(Array(nums[0..<mid]))
    let right = mergeSort(Array(nums[mid..<nums.count]))
    // 合并两段数据
    let result = merge(left, right)
    return result
}
func merge(_ left: [Int],_ right: [Int]) -> [Int] {
    var result = [Int]()
    // 两边数组合并游标
    var l = 0, r = 0
    let lCount = left.count, rCount = right.count
    // 注意不能越界
    while l < lCount && r < rCount {
        // 谁小合并谁
        if left[l] > right[r] {
            result.append(right[r])
            r += 1
        } else {
            result.append(left[l])
            l += 1
        }
    }
    // 剩余部分合并
    if l < lCount {
        result.append(contentsOf: left[l..<lCount])
    }
    if r < rCount {
        result.append(contentsOf: right[r..<rCount])
    }
    return result
}
```

# 堆排序（选择排序的优化）
最好、最坏、平均都是nlogn, 不稳定
``` swift
func heapSort(nums: inout [Int]) {
    var index = nums.count
    heapify(&nums)
    while index>1 {
        index -= 1
        nums.swapAt(0, index) //选择最大元素（根），并移到最后
        siftDown(&nums, index: 0) //下滤修复新的堆顶元素供下一次选择
    }
}
func heapify(_ nums: inout [Int]) {
    //自下而上的下滤比自上而下的上滤建堆性能更高，从size/2 - 1最后一个非叶子节点开始自下而上的下滤
    for i in stride(from: (nums.count >> 1)-1, through: 0, by: -1) {
        siftDown(&nums, index: i)
    }
}

func siftDown(_ nums: inout [Int], index: Int) {
    var parentIndex = index
    while ((parentIndex << 1) + 1) < nums.count { //是否已经是叶子节点，是叶子节点无须继续下滤了
        var maxSubIndex = (parentIndex << 1) + 1 //默认选最大为左子节点
        if maxSubIndex+1 < nums.count && nums[maxSubIndex+1] > nums[maxSubIndex] { //注意越界
            maxSubIndex += 1 //更新最大节点为右节点
        }
        if nums[parentIndex] > nums[maxSubIndex] { break } //比最大子节点大，无需下滤了
        nums.swapAt(parentIndex, maxSubIndex)
        parentIndex = maxSubIndex
    }
}
```
