# 位运算
[一些常用的算法技巧总结](https://mp.weixin.qq.com/s/6JJdV9oXJznkGt4gSOlR9g)
[位运算技巧](https://mp.weixin.qq.com/s/C6o6T9ju34vAxNBg5zobWw)

* &与运算，都为1才为1，主要作用如下：
	1. 探测奇偶数，x&1 == 1为奇数
	2. 探测特定位上的数（x&100探测x的倒数第三位是0还是1）
* ^异或运算，不同则为1，相同位0，支持交换律和结合律。
	1. 不同额外临时变量交换两个数x、y（x = x ^ y; y = x ^ y; x = x ^ y）
	2. 异或相同则抵消找不同的数（2^7^7 = 2）
* 用移位运算代替乘除法，比如：
	1. N / 2 等价于 n >> 1
	2. N / 4 等价于 n >> 2
	3. N / 8 等价于 n >> 3。

2. 对于排好序的，使用前后双指针，如果要找出不包含重复的情况（a,b和b,a是一种情况），那么在需要在lo和hi更新的时候，分别跳过重复的元素。

``` swift
int lo = start, hi = size - 1;
while (lo < hi) {
    int sum = nums[lo] + nums[hi];
    int left = nums[lo], right = nums[hi];
    if (sum < target) {
        while (lo < hi && nums[lo] == left) lo++; //去重
    } else if (sum > target) {
        while (lo < hi && nums[hi] == right) hi--; //去重
    } else {
        res.push_back({left, right});
        while (lo < hi && nums[lo] == left) lo++; //去重
        while (lo < hi && nums[hi] == right) hi--; //去重
    }
}	
```
