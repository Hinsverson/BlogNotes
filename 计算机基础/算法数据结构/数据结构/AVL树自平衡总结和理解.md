# AVL树自平衡总结和理解

[小码哥《恋上数据结构与算法》笔记（九）：平衡二叉搜索树（AVL） - 掘金](https://juejin.im/post/5e057217f265da33d912ecfe#heading-19)

* BST树添加导致的失衡最坏的情况是所有祖先节点都失衡，但是父节点、非祖先节点都不可能失衡。
* BST树删除节点可能会导致父节点或祖先节点失衡（只有一个节点会失衡），其他节点都不可能失衡。
* BST树删除后对失衡节点进行左右旋转处理后可能会导致更高处的祖先节点再次失衡。极端情况下，所有祖先节点都需要进行恢复平衡的操作，共O(logn)次调整。

# 通过二叉搜索树如何实现AVL树？
首先BST在添加、删除后都可能导致父亲或者祖先节点失衡，而失衡调整应该在BST添加、删除节点后。

## afterAdd(node)、afterRemove(node) 自平衡函数的实现的基本思路是：
* 通过newNode的parent属性，一路往上找，找到高度最低的那个失衡节点，然后对失衡节点进行调整。 
* 在添加时只要这个高度最低的失衡节点恢复平衡，那么所有的节点都恢复平衡了，直接提前break。
* 在删除时要注意对一个失衡节点进行左/后旋后，可能会导致祖先节点再次失衡的情况，所以不能break。极端情况下，所有祖先节点都需要进行恢复平衡的操作，共O(logn)次调整。

## isBalanced(node)函数实现的基本思路是：
* 判断节点平衡的方式是比较左右子节点高度，所以需要给节点增加一个高度属性。
* 如果节点是平衡的，只需要更新节点高度，通过获取左右子树最大高度 + 1即可。

# 二叉搜索树导致失衡的4种情况和解决办法？：
g是失衡节点，p是g左右子树高度最高的子节点，n是p左右子树高度最高的子节点。LL表示n在失衡节点g的左边子节点p的左边，RR表示n在失衡节点g的右边的右节点p的右边，LR表示n在失衡节点g的左边子节点p的右边，RL表示n在失衡节点g的右边子节点p的左边。
* 失衡 LL - 右旋传（单旋）rotateRight(g)
* 失衡 RR - 左旋转（单旋）rotateLeft(g)
* 失衡 LR - RR左旋转，LL右旋转（双旋）先rotateLeft(p)，再rotateRight(g)
* 失衡 RL - LL右旋转，RR左旋转（双旋）先rotateRight(p)，再rotateLeft(g)

# 如何对某个节点（这里是g）进行右旋？
对某个节点右旋相当于把原来左节点的右节点变为旋转后它的左节点，自己变成原来左节点的右节点。
![](AVL%E6%A0%91%E8%87%AA%E5%B9%B3%E8%A1%A1%E6%80%BB%E7%BB%93%E5%92%8C%E7%90%86%E8%A7%A3/917220D0-38E9-46A0-B881-1A143CA45770.png)
	* g.left = p.right
	* p.right = g
	* 让p成为这颗子树的根节点，改变之后整棵树仍然是一颗二叉搜索树：T0 < n < T1 < p < T2 < g < T3，整棵树都达到平衡。
右旋还需要注意维护：
	* T2，p，g的parent属性。
	* 先后更新g，p的高度属性。
	
# 如何对某个节点（这里是g）进行左旋？
对某个节点左旋相当于把原来右节点的左节点变为旋转后它的右节点，自己变成原来右节点的左节点。![](AVL%E6%A0%91%E8%87%AA%E5%B9%B3%E8%A1%A1%E6%80%BB%E7%BB%93%E5%92%8C%E7%90%86%E8%A7%A3/A7C5C076-349C-42AC-AACF-FB92B20969D0.png)
	* g.right = p.left
	* p.left = g
	* 让p成为这颗子树的根节点。
左旋还需要注意维护：
	* T1，p，g的parent属性。
	* 先后更新g，p的高度属性。
