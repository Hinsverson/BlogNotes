# 深入理解计算机系统

# 学习方法
[如何阅读《深入理解计算机系统》这本书？ - 知乎](https://www.zhihu.com/question/20402534)

https://github.com/EugeneLiu/translationCSAPP

我觉得吧，直接上手lab，你啥时候把那几个lab做完，我觉得你就达到写这本书人希望你达到的目的了。 那就拿第二个lab bomblab来说吧. 不用担心不知道如何开始，直接去官网下lab，里头配套提供了非常详实，细节的handout，你把handout看明白，然后去看对应书中相关章节，边做lab边参考书。你自然就会明白你要去了解汇编的语法，程序的存储结构等等。你有目标要把lab做出来，你自然会有动力去学习。如果只是干巴巴的看书或者看视频，是很难坚持下去的。
